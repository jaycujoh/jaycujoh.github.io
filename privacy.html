Privacy policy

ZION HUD · last updated 13 November 2026

ZION HUD is a personal dashboard used only by its owner, on the owner's own home server. This policy explains what it does with Google user data.

What it accesses

With the owner's permission, ZION HUD uses the Google Calendar API to read the owner's calendars and events, and to create, update, move and delete events when the owner asks it to. It also reads the email address of the signed-in account, to show which account is connected.

How the data is used

The data is used only to show the owner's calendar in the dashboard and to carry out the changes the owner makes there. It is not used for advertising, profiling or any other purpose.

Where it is stored

Events are cached in memory on the owner's home server, and the sign-in token is stored on that server in a file only the owner's account can read. Nothing is sent to any third party, and the dashboard is reachable only from the owner's private network.

Sharing

Google user data is never sold, shared or transferred to anyone. ZION HUD's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops all access straight away; cached events are cleared when the dashboard next restarts.

Contact

Questions about this policy can be sent to the support email shown on the app's Google sign-in screen.
